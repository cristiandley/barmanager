BarManager

Hide and group your macOS menu bar icons.

|
9:41

Click the chevron.

Install

brew install cristiandley/tap/barmanager

Features

  • One click hides the icons that you select.
  • Groups: visible, hidden, and always hidden.
  • Colored backgrounds show each group.
  • CLI control: BarManager toggle.
  • No dependencies. Swift and AppKit only.
